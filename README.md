# Karthikeyan K. — Full-Stack Developer Portfolio

A premium, minimalist dark-themed developer portfolio designed and engineered following the approved visual design board, featuring editorial typography, Deep Teal / Muted Turquoise palette, and faithful section composition.

---

## 🎨 Design Philosophy & Tokens

Built with the **Deep Teal / Muted Turquoise** palette:

| Token | Hex | Role |
|---|---|---|
| **Main Background** | `#0B1011` | Primary dark slate-charcoal canvas |
| **Card Background** | `#141C1D` | Project cards, highlight boxes, skill tiles |
| **Elevated Surface** | `#192324` | Badge containers, icon backdrops, elevated fills |
| **Borders** | `#263536` | Hairline dividers and framing borders |
| **Primary Accent** | `#669B96` | Deep teal / muted turquoise for CTAs, active states, icons |
| **Accent Highlight** | `#A4C5C0` | Soft turquoise highlights and badges |
| **Primary Text** | `#F1F4F2` | High-contrast editorial titles and headers |
| **Secondary Text** | `#A5B2AE` | Body copy, descriptions, role titles |
| **Muted Text** | `#71817D` | Metadata, dates, auxiliary subtitles |

---

## 🛠️ Tech Stack & Typography

- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Motion & Interactions:** Framer Motion (`framer-motion`)
- **Typography:** Space Grotesk (Headings), Inter (Body text), IBM Plex Mono (Technical labels)
- **Icons:** Official SVG vector logos
- **Build Tool:** Vite 6

---

## 🚀 Key Sections (Matching Design Board)

1. **Navigation:** KK monogram, section links with active state indicator, outlined `Resume ⤓` button, and scroll progress bar.
2. **Hero:** Two-column editorial composition with Karthik's actual portrait, concentric architectural linework, soft teal aura, floating `</> Turning ideas into real products.` badge, primary CTA buttons (`View My Projects →` and `Download Resume ⤓`), and social link icons.
3. **Featured Projects (3 Horizontally Aligned Cards on Desktop):**
   - **FinTrack:** Analytics dashboard visual preview with cash flow bar chart, tech pills, verified >60% & >80% query latency improvements, and links.
   - **ResumeIQ:** Dual-panel skill match & feedback preview, tech pills, verified 9.8m → 8.7s (~98.5%) latency cut, 12 passing tests, and links.
   - **DayFlow:** Telegram task assistant UI with inline buttons, tech pills, and n8n webhook workflow.
4. **About (Split Layout):** "Turning Ideas into Scalable Solutions" narrative on the left with three compact icon-led highlights on the right (`Problem Solver`, `Team Player`, `Continuous Learner`).
5. **Experience (My Journey):** Clean timeline with teal nodes showing role, company, and dates for Arshith Fresh India, BDreamz Global Solutions, and ZF Commercial Vehicle.
6. **Skills (Tech Stack Icon Grid):** Compact individual icon tiles with official SVG logos and technology labels across Frontend, Backend, Database, AI & Automation, and Developer Tools.
7. **Contact & Footer:** "Let's Build Something Great Together", `Get In Touch →` CTA, email with copy-to-clipboard, LinkedIn, GitHub, and minimal footer with back-to-top control.
