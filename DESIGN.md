# DESIGN.md – Design System & Architecture Specification
**Portfolio for Karthikeyan K. — Full-Stack Developer**

---

## 1. Visual Reference & Layout Composition

Directly recreated based on the approved portfolio design board:
- **Design Philosophy:** Premium Dark Minimalism × Editorial Developer Portfolio
- **Palette Theme:** Deep Charcoal / Muted Turquoise (Deep Teal)
- **Visual Balance:** Strong asymmetric two-column hero with prominent executive portrait, curved architectural linework, three horizontally aligned project cards on desktop, split about section with three icon-led highlights, streamlined experience timeline, compact icon-based technology grid, and closing contact section.

---

## 2. Approved Colour Palette & Tokens

Strict adherence to the approved palette specification:

| Token Name | Hex Code | Purpose & Usage |
|---|---|---|
| `Main Background` | `#0B1011` | Primary dark slate-charcoal canvas |
| `Card Background` | `#141C1D` | Project cards, highlight boxes, skill tiles |
| `Elevated Surface` | `#192324` | Badge containers, icon backdrops, elevated fills |
| `Borders` | `#263536` | Hairline dividers and framing borders |
| `Primary Accent` | `#669B96` | Deep teal / muted turquoise for CTAs, active states, icons |
| `Accent Highlight` | `#A4C5C0` | Soft turquoise highlights and badges |
| `Primary Text` | `#F1F4F2` | High-contrast editorial titles and headers |
| `Secondary Text` | `#A5B2AE` | Body copy, descriptions, role titles |
| `Muted Text` | `#71817D` | Metadata, dates, auxiliary subtitles |

---

## 3. Typography Hierarchy

1. **Headings:** `Space Grotesk` (clean, modern, geometric neo-grotesque)
2. **Body Text:** `Inter` (high-readability, neutral sans-serif)
3. **Small Technical Labels:** `IBM Plex Mono` (dates, tags, benchmark metrics)
